## Boundaries not claimed solved

- **External users:** 10 isolated synthetic tenants, not 10 recruited human usability testers.
- **Hardware passkeys:** virtual authenticator tested, hardware cross-device compatibility needs physical devices.
- **Real email send / inbox / provider payouts:** no Apollo, OpenAI or Resend production API keys provided for this audit, and no real email was dispatched; credentials, verified sender, DNS records and real provider webhooks must be connected and measured.
- **Sina Founder OS / Company OS / Motor / Runway:** signed event bridge and authorization contracts exist; no verified live endpoints for four-way execution are configured, and no independent end-to-end receipt is claimed.
- **Rendering diversity:** Chromium desktop/mobile automated, not exhaustive Firefox, Safari, screen readers or accessibility certification.

## Launch rules

Deploy only after GitHub CI and Browser Regression are green, Railway source commit matches the merged main commit, readiness is HTTP 200, and guest/session tests pass on canonical production domain. Keep live sending disabled unless a saved workspace activates a campaign and connects a verified sender. Do not call queued/sent/replied state "collected revenue".
